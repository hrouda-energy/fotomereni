# Fotoměření v4

**Fotoměření bylo vyvinuto pro měření obálky budov zvenku.** Vyfotografujte budovu zvenku a přímo na snímcích měřte délky, rozměry oken a dveří, plochy a úhly. Pro nastavení měřítka použijte známé rozměry ve stejné rovině jako měřené prvky.

## Stažení a spuštění

1. Na stránce repozitáře klikněte na **Code → Download ZIP** a archiv rozbalte.
2. Otevřete soubor `fotomereni-prototyp-v4.html` v prohlížeči. Aplikaci můžete používat offline.
3. Podle [návodu](NAVOD.md) načtěte snímek, proveďte kalibraci a začněte měřit.

Přesnost měření závisí na snímku, kalibraci a zadaných referenčních rozměrech.
